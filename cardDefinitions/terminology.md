# Resource types
| Name | Abbreviation |
|-|-|
| Energy | E |
| Spin | S |
| Pressure | P|
| Drive | M |
| Damage | W |


Resources noted as repeated letter i.e. EE have a symbol drawn for each letter

Resources noted as a number followed by a letter have that number written next to one symbol
The number may also be an algebraic expression i.e. 4XW would be noted as 4 X damage symbol
- in these cases the meaning of X is explained in the rules text

# Keywords

Components may have any of the following keywords

| Fragile | If this component takes weapon damage it is destroyed as if it had a durability of 1 |
| Spin up X | At the start of each turn add a spin counter (max X) and remove them all if the weapon attacks, hits a wall or becomes inactive.|
| Forks | If the opposing robot is in line with the forks during contact, they become raised for this contact (does not work while inverted) |
| Wedge | If this component makes contact, the opponent becomes raised for this contact and this component has double absorption against weapon contact (does not work while inverted) |
| Invertible | This component works inverted. |
| Self-right | If a turn ends without contact and this robot is inverted, invert it.|
| Reset | This weapon is inactive the turn after it is used. (this does not cause the robot to be considered knocked out if it is also a self righter) |
